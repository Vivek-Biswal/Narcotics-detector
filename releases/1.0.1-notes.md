# NarcTrace 1.0.1 preview

Fixes a page-wide click handler accidentally assigned to the HTML theme attribute. Clicking any login field previously rebuilt the page, removed focus, and cleared the fields. Theme handlers now target buttons only, and changing themes on the login page preserves its input elements.

Also avoids form resets from redundant signed-out notifications, restores authenticated sessions into the workspace, prevents duplicate submissions, and explains invalid credentials, unconfirmed email addresses, and connectivity errors.

Verification: six automated tests passed; production website build passed. Browser testing confirmed keyboard entry in both fields, preservation during theme changes, successful submission to the live authentication endpoint with invalid test credentials, and a visible invalid-credentials response with the submit button enabled again. A successful account login was not tested because no confirmed test-account credentials were provided.

The project currently requires email confirmation and has Google sign-in disabled. These backend settings were not changed. Confirm your registered email before signing in; Google OAuth still needs administrator setup.

Install NarcTrace-1.0.1-preview.apk over the previous preview. The package ID and local debug signing key are unchanged, and Android versionCode is increased to 2.

Android build succeeded. APK signature verified and signing-certificate fingerprint matched version 1.0. This updated APK was not separately tested on a physical phone.
