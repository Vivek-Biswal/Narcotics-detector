# NarcTrace 1.0.2 preview

Android Back returns through visited pages, first closing an open record, mobile menu, or active camera. At the overview it keeps the app open.

Adds the official Capacitor App and Browser plugins, Android callback intent filter, and PKCE code exchange. Removes the unconditional Android Google sign-in block. Google provider credentials and redirect allowlist configuration are still required in Supabase; see website/SETUP.md. No Firebase project was necessary or created.

Ten JavaScript tests and the production website build passed. Successful Google-account sign-in remains unverified because provider configuration and authenticated dashboard access are unavailable.

Android APK and instrumentation build succeeded; signature verified with the same certificate as previous previews. Installation succeeded. The native Android Back-dispatcher instrumentation test passed, covering login → guide → history → overview, staying open at the root, and dismissing a record dialog. Espresso physical-key injection was blocked by an emulator System UI ANR, so physical-button behavior on a real phone remains untested.
